# Фото объектов

Добавляй реальные фотографии в эту папку с такими именами:

- case-01-before.webp
- case-01-after.webp
- case-02-before.webp
- case-02-after.webp
- case-03-before.webp
- case-03-after.webp

Рекомендуемый формат: WebP или JPG, горизонтальные фотографии.

Кейс 01 — демонтаж помещения.
Кейс 02 — подготовка основания.
Кейс 03 — фальшпол.

При отсутствии файла интерфейс автоматически показывает аккуратный fallback, поэтому сайт не ломается.
